Data Scientist | Biostatistician | Budapest, HU

I build statistical models for causal inference and biostatistics, with a focus on Bayesian methods. Turning messy, high-volume data into robust and actionable decisions. On the applied forecasting side, I work on TidyTransit, a real-time data-streaming and forecasting pipeline for transit systems, inspired by personal frustration about the Budapest transit system. I write about the methods behind this work on Field Notes.
